# Datos de demostración

Todo el contenido de este repositorio es ficticio y existe únicamente para mostrar las capacidades técnicas del RAG operacional.

| Recurso | Uso en la demostración |
| --- | --- |
| `demo-data/documents/contrato_distribucion_bmw_hidalgo.pdf` | Consultas sobre condiciones de distribución, garantía y facturación. |
| `demo-data/documents/contratos_proveedores_reparto_bmw_hidalgo.pdf` | Consultas sobre servicios de reparto y proveedores. |
| `demo-data/sql/piezas_bmw_hidalgo.sql` | Catálogo ficticio de refacciones, precios y existencias. |
| `demo-data/sql/facturas_bmw_hidalgo.sql` | Facturas y clientes ficticios para preguntas cuantitativas. |
| `migrations/20260917001044_seed-bmw-demo.sql` | Datos demo usados por el esquema de InsForge. |

No se deben sustituir estos ejemplos por información real sin una revisión de privacidad, permisos, políticas de retención y control de acceso.
