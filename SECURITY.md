# Política de seguridad

Si encuentras una vulnerabilidad, no publiques claves, datos personales, URLs privadas ni detalles de explotación en una incidencia pública.

Usa una asesoría de seguridad privada de GitHub para este repositorio e incluye una descripción breve, pasos de reproducción, impacto potencial y una recomendación de corrección. Grun Agency Tech revisará el reporte antes de divulgarlo.
